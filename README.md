## 🏗️ Architectural & UX/UI Highlights

The application design adheres to modern production web design aesthetics and accessibility standards set by industry leaders like Apple, Vercel, Stripe, and OpenAI:
- **Fluid Responsive Typography**: Built upon dynamic CSS `clamp()` viewport formulas ($320\text{px}$ up to $1920\text{px}$) to eliminate line clipping, awkward wrapping, and fixed pixel constraints.
- **Native Touch Ergonomics**: Strict global enforcement of WCAG 2.2 AA compliant $44\times 44\text{ px}$ minimum interactive touch dimensions across all buttons, dropdowns, chips, and controls.
- **iOS Zoom Defense**: Input form typography standardized to $\ge 16\text{px}$ to prevent Safari on iOS from triggering disruptive automatic viewport screen zooming during interaction.
- **60 FPS Hardware Acceleration**: Hover states and card animations run exclusively on GPU-accelerated css transforms (`translate3d` and explicit `will-change: transform, box-shadow`) for silk-smooth interaction across touch devices.
- **Built-in SEO & Internationalization**: Full English and Spanish localization engines paired with dynamic JSON-LD structural schema, semantic metadata, and optimized OpenGraph social previews.

## 💻 Local Development & Verification Guide

### Prerequisites
* Node.js (v18 or v20+ recommended)
* npm (v9+) or yarn / pnpm
* Git

### Quick Start
1. **Clone the repository**:
   ```bash
   git clone https://github.com/MuhammadMinhaj229/portfollio.git
   cd portfollio
   ```

2. **Install project dependencies**:
   ```bash
   npm install
   ```

3. **Launch local interactive development server**:
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.

4. **Execute strict automated CI production build**:
   To test zero-warning compilation locally under Netlify-compatible CI standards:
   ```powershell
   $env:CI="true"; npm run build
   ```
   An optimized, static output bundle will be compiled into the `/build` directory.

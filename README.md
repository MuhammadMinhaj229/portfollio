## Getting Started

### Prerequisites

- Node.js 18+ (Node 20+ recommended)
- npm or pnpm

### Installation

```bash
git clone https://github.com/MuhammadMinhaj229/portfollio.git
cd portfollio
npm install
```

### Local Development

```bash
npm run dev
```

### Production Build & Preview

```bash
npm run build
npm run preview
```
